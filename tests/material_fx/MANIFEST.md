# Material FX 私人回归清单

本清单只登记已确认问题和验收条件，不包含真实照片、照片哈希、私人 Ground Truth
文件或验收截图。真实样片必须由维护者在本地私有目录提供，且不得复制到仓库。

## Case 001

- 状态：待本地真实样片复验；
- 已知旧结果：未识别到可稳定确认的素材特效；
- 已知视觉效果：RGB 色彩偏移、胶片颗粒、高斯模糊或柔化；
- 验收条件：结果不得为“未发现明显素材特效”；必须包含 `RGB 色彩偏移`；
  必须包含一种颗粒标签；必须包含 `高斯模糊` 或 `柔化`；
- 颗粒粗细：真实 Ground Truth 未确认，不得写死。

## Case 002 / S95-5

- 状态：待本地真实样片复验；
- 已知旧结果：未识别到可稳定确认的素材特效；
- 已知视觉效果：细颗粒；
- 验收条件：必须包含且明确显示 `细颗粒`，不得回退为无效果文案。

## 本地执行约束

1. 样片目录必须位于仓库外；
2. 运行前后记录输入 SHA-256，确认原图未改变；
3. 输出写入仓库外临时目录；
4. 只提交脱敏后的汇总，不提交照片、哈希、报告 PNG 或私人 JSON；
5. 缺少真实样片时保持“待验收”，不得用合成图冒充通过。
